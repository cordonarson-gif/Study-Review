OpenMAIC 全功能详细拆解（开发复现版）
 
以下按「架构层→核心管线→智能体系统→前端组件→业务模块→集成部署」逐层拆解，每个功能点明确输入输出、核心逻辑与技术依赖，可直接用于代码复刻。
 
一、整体技术架构与基础栈
 
1.1 分层架构
 
层级 核心职责 技术选型 
前端表现层 课堂渲染、交互响应、多模态展示 Next.js + React + TypeScript + Tailwind CSS 
智能体编排层 多角色调度、交互模式控制、状态流转 LangGraph 多智能体状态机 
课程生成层 内容理解、大纲生成、多场景内容生产 两阶段生成管线 + MinerU 文档解析 
动作执行层 统一指令下发、驱动前端特效/语音/绘图 28+ 标准化动作协议 
模型适配层 多LLM供应商统一调用、流量路由 OpenAI 兼容 API 抽象层 
部署层 运行环境、容器化、一键部署 Docker / Vercel / 自托管 
 
1.2 基础依赖与环境
 
- 运行环境：Node.js ≥ 20，pnpm ≥ 10
- 开源协议：AGPL-3.0，提供商业授权通道
- 默认模型：Gemini 3 Flash（质量速度平衡）；高质量模式：Gemini 3.1 Pro
- 兼容模型：OpenAI、Anthropic、DeepSeek 及所有 OpenAI 格式兼容接口
 
二、两阶段课程生成管线（核心引擎）
 
2.1 输入源支持
 
1. 文本主题输入：用户输入任意自然语言主题描述（如「30分钟从零入门Python」）
2. 文档上传输入：支持 PDF 格式（论文、教材、讲义），由 MinerU 引擎提取文本、公式、图表语义
3. 聊天端输入：通过 OpenClaw 从飞书/Slack/Telegram 等聊天软件接收文本/文件
 
2.2 第一阶段：结构化课程大纲生成
 
输入
 
- 原始素材：主题文本 / 解析后的文档全文
- 可选参数：课程总时长、难度等级、目标受众、侧重方向
 
核心处理逻辑
 
1. 内容拆解：语义分析提取核心知识点、概念层级、逻辑依赖关系；PDF输入同步提取公式、图表说明
2. 教学编排：按「引入→讲解→练习→总结」规律排序知识点，划分章节与单节时长
3. 场景匹配：为每个知识点匹配最优呈现形式（幻灯片/测验/模拟实验/PBL）
4. 目标对齐：为每章设定明确学习目标，匹配对应测验考点
 
输出（结构化JSON）
 
- 课程元数据：标题、总时长、难度、适用人群、整体学习目标
- 章节列表：
- 章节ID、标题、时长、分项目标
- 场景类型枚举：幻灯片授课 / 互动测验 / 模拟实验 / PBL项目
- 核心知识点清单、预设互动节点位置
 
2.3 第二阶段：分场景内容生成
 
按大纲场景类型，分别生成可被前端直接渲染的标准化场景数据。
 
场景1：幻灯片授课场景
 
生成内容：
 
1. 幻灯片页面集
- 每页结构：标题、正文要点、配图/图表、LaTeX 公式
- 内容出现时序：逐条显示的节点顺序
2. 语音旁白脚本
- 逐页口语化讲解台词，标注停顿、重音、语速节点
- 与页面内容、特效时序精准对齐
3. 授课特效指令
- 聚光灯：每页重点区域的高亮坐标、停留时长
- 激光笔：重点内容的指示移动路径、速度
 
场景2：互动测验场景
 
生成内容：
 
1. 题目集
- 题型：单选题、多选题、简答题
- 每题属性：对应知识点、难度、题干、选项、标准答案
2. 评分规则
- 客观题：正误判断逻辑
- 主观题：得分点、关键词权重、语义相似度评分维度
3. 反馈体系
- 错题逐题解析，关联对应知识点
- 知识盲点识别逻辑、个性化复习路径推荐
 
场景3：HTML 模拟实验场景
 
生成内容：
 
1. 单文件HTML代码：完整 HTML/CSS/JS，无外部依赖，浏览器沙箱直接运行
2. 实验类型覆盖
- 物理模拟器：力学、电磁学等现象的参数化模拟
- 算法可视化：排序、搜索、数据结构操作的分步动效
- 流程图演示：逻辑流程、业务流程的交互式分步展示
3. 引导体系：实验目的、操作指引、配套思考题、AI讲解旁白
 
场景4：PBL 项目制学习场景
 
生成内容：
 
1. 项目框架：主题背景、最终交付物要求、里程碑划分与验收标准
2. 角色体系：3-5种可选项目角色，各角色职责、能力人设、对应AI协作逻辑
3. 协作流程：分阶段任务分配、AI发言逻辑、进度追踪与交付物检查点
 
三、多智能体编排系统
 
3.1 角色体系（独立人设 + Prompt 约束）
 
1. AI 主讲教师
- 职责：课程主讲、知识点讲解、发起讨论/测验、点评发言、课堂总结
- 权限：控制幻灯片进度、调用白板、切换交互模式
- 可配置：教学风格（严谨/通俗/互动型）、语速、人设
2. AI 助教
- 职责：辅助答疑、整理课堂笔记、推送资料、基础问题解答
- 能力：实时记录讨论要点、课后生成总结
3. AI 同学（3-5名）
- 差异化人设：知识基础、观点立场、发言活跃度各不相同
- 职责：参与讨论、发起提问、参与辩论、组队完成PBL任务
 
3.2 三大交互模式（LangGraph 状态机驱动）
 
模式1：课堂讨论模式
 
- 触发：预设讨论节点 / 教师主动发起
- 状态流转：
1. 发起：AI教师抛出议题与规则
2. 自由发言：AI同学按人设轮流表达观点
3. 学生介入：学生文本/语音输入自动接入对话
4. 点名机制：AI教师可随机点名学生回答
5. 收尾：教师梳理要点、总结结论，回归授课
- 配套：讨论过程中AI可同步在白板绘制论点思维导图
 
模式2：圆桌辩论模式
 
- 触发：争议性知识点、思辨类主题章节
- 状态流转：
1. 立论：公布辩题，分配正反/多方立场
2. 轮流陈词：各立场AI依次发表核心观点
3. 自由辩论：AI互相反驳、补充论据，白板同步绘制论点逻辑图
4. 学生参与：学生可加入任意阵营发言
5. 总结：各方陈词，教师做中立点评与知识点总结
- 约束：每个智能体绑定固定立场，Prompt 限制发言角度
 
模式3：自由问答模式
 
- 触发：专门答疑环节 / 学生主动提问
- 处理逻辑：
1. 接收学生输入（文本/ASR转写）
2. 解析问题，匹配对应知识点
3. 选择解答形式：纯语言解答 / 跳转对应幻灯片 / 白板绘图讲解
4. 输出解答，追问理解程度，按需补充
 
3.3 调度核心能力
 
- 轮次控制：按模式控制发言顺序、单轮发言长度
- 上下文管理：维护整节课对话上下文，确保发言连贯
- 无缝切换：授课中可随时切换三种交互模式
- 优先级：学生发言自动打断AI轮次，优先处理
 
四、多模态课堂前端组件
 
4.1 智能幻灯片播放器
 
- 渲染能力：文本、图片、图表、LaTeX 公式原生渲染
- 授课特效：
- 聚光灯：指定区域高亮，其余区域压暗，引导注意力
- 激光笔：模拟教师指示，沿路径平滑移动
- 逐条出现：要点按讲解顺序逐行动画展示
- 控制：AI自动控速，支持学生手动暂停/前进/后退
- 音画同步：语音旁白与页面、特效时序毫秒级对齐
 
4.2 协作式实时白板
 
- 画布基础：无限画布、缩放平移、图层管理
- 支持元素：
1. 基础图形：直线、矩形、圆形、箭头
2. 文本公式：手写体文字、LaTeX 公式渲染
3. 流程图：标准符号、连接线自动吸附
4. 数学推导：方程分步求解、演算过程书写
- 交互逻辑：
- AI分步绘制动画，模拟真实书写过程
- 学生可同步标注、书写
- 多智能体同时绘制的图层避让、位置防重叠
- 导出：白板内容可导出为图片，插入PPT
 
4.3 语音交互系统
 
1. TTS 语音合成
- 多引擎适配，多音色对应不同角色
- 支持语速、情感调节，匹配授课语气
- 语音播放同步显示文字字幕
2. ASR 语音识别
- 学生语音输入实时转文字
- 端点检测、自动断句，支持免提问答
 
4.4 动作执行引擎
 
- 统一协议：后端下发标准 JSON 动作指令，前端统一执行
- 28+ 动作分类：
- 语音类：播放、暂停、切换音色
- 白板类：绘图、书写、清屏、缩放
- 幻灯片类：切页、聚光灯定位、激光笔移动、逐条展示
- 交互类：弹出测验、开启讨论、触发输入框
- 特效类：页面转场、高亮动画、提示弹窗
 
五、互动学习与测评模块
 
5.1 互动测验系统
 
- 答题交互：单选/多选点击即提交，简答题文本输入
- AI 评分：
- 客观题：即时正误判断，显示正确答案
- 主观题：关键词+语义相似度+逻辑完整性多维度评分
- 学习分析：
- 正确率统计、错题知识点分布
- 识别薄弱点，生成个性化复习建议
- 推荐对应章节重学、补充练习
 
5.2 HTML 模拟实验
 
- 运行：浏览器沙箱直接运行，无需安装
- 交互：参数可调节、步骤可暂停/步进/重置、实时数据展示
- AI 引导：实验过程中同步讲解原理、提示操作要点
 
5.3 PBL 项目制学习
 
- 开局：学生选择项目角色，确定分工
- 流程：AI按里程碑推送任务、发起讨论、评审交付物
- 验收：最终成果AI评分，给出优化建议
 
六、内容导出能力
 
6.1 PPTX 导出
 
- 输出：标准  .pptx  文件，完全可编辑
- 保留内容：文本、图片、图表、LaTeX 公式（转为可编辑公式对象）、白板绘图（转为图片）
- 兼容：PowerPoint / WPS 直接打开编辑
 
6.2 互动 HTML 导出
 
- 输出：单文件 HTML，内嵌所有资源
- 保留能力：完整幻灯片播放、语音旁白、互动测验、评分反馈、模拟实验
- 使用：无需部署，双击即可在浏览器运行
 
七、外部集成
 
7.1 多 LLM 适配层
 
- 统一接口抽象，屏蔽厂商差异
- 支持：OpenAI、Anthropic、Google Gemini、DeepSeek、所有 OpenAI 兼容接口
- 配置：环境变量配置密钥，支持全局默认模型、分场景指定模型
 
7.2 OpenClaw 多端集成
 
- 支持平台：飞书、Slack、Discord、Telegram、WhatsApp 等 20+ 聊天应用
- 能力：聊天窗口内发送主题/文件即可生成课程，返回课程链接直达课堂
- 安装方式： clawhub install openmaic 
 
八、部署方案
 
8.1 本地开发
 
bash
  
# 1. 克隆与安装
git clone https://github.com/THU-MAIC/OpenMAIC.git
cd OpenMAIC
pnpm install

# 2. 配置
cp .env.example .env.local
# 填入至少一个 LLM 的 API 密钥

# 3. 启动
pnpm dev
# 访问 http://localhost:3000
 
 
8.2 生产部署
 
1. Vercel：关联仓库一键自动构建部署
2. Docker： docker compose up --build  容器化启动
3. 自托管： pnpm build && pnpm start  部署到自有服务器
