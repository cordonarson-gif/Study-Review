Consider the Logistic Growth Model defined by the following differential equation:
\frac{dP}{dt} = rP \left(1 - \frac{P}{K}\right)
If the initial population is P(0) = P_0, what is the value of t when the population reaches exactly half of its carrying capacity K?
CORRECT ANSWER: A

Analysis: The solution to the logistic differential equation is:

P(t) = \frac{K}{1 + \left(\frac{K - P_0}{P_0}\right) e^{-rt}}

To find the time when P(t) = K/2, we set the denominator equal to 2, which leads directly to the result in Option A.
